# Loop

**A better way to experience your music.**

Loop is a browser extension that transforms your music listening experience with synchronized lyrics, dynamic visualizations, and a customizable playback interface.

Designed with performance, flexibility, and aesthetics in mind, Loop brings your music and lyrics together in a seamless, immersive experience.

### Installation
<details>
<summary><strong>Chromium</strong></summary>

1. Download the latest `Source code.zip` from the Releases tab and extract it.
2. Open your browser's extension management page:
  - **Chrome:** `chrome://extensions`
  - **Edge:** `edge://extensions`
  - **Brave:** `brave://extensions`
3. Enable **Developer mode** (toggle in the top-right or sidebar).
4. Click **Load unpacked**.
5. Select the directory containing `manifest.json` from the extracted archive.

</details>

<details>
<summary><strong>Firefox</strong></summary>

1. Download the latest `Source code.zip` from the Releases tab.
2. Open the `about:config` page.
3. Search for `xpinstall.signatures.required` and change it to `false`.
4. Navigate to `about:addons`.
5. Click the gear icon in the top-right and select **Install Add-on From File**.
6. Select the downloaded ZIP file.

</details>

### Features

- **Synchronized Lyrics** – Follow along with synchronized lyrics using multiple providers and supported lyric formats.
- **Dynamic Visualizations** – Enhance your listening experience with customizable visual effects and rendering configurations.
- **Customizable Experience** – Fine-tune animations, lyric rendering, visual styles, and playback presentation.
- **Multiple Lyrics Providers** – Retrieve lyrics from different sources with configurable provider priorities.
- **Immersive Interface** – Album artwork, playback controls, and lyrics come together in a unified interface.
- **Performance Focused** – Optimized rendering pipelines designed to keep the experience smooth and responsive.

Loop is built for desktop browsers, with a focus on delivering a polished and consistent listening experience.
